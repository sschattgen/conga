CoNGA Example Notebooks (rendered)

These are static, pre-run renders of CoNGA's example Jupyter notebooks, including their original output (plots, tables). The notebook source files in the repository no longer carry these outputs inline — they were stripped to keep the repository lightweight. View the results here, or clone the repo and run the notebooks yourself to reproduce them.

  • simple_tcrdist_example — minimal walkthrough of the TcrDistCalculator API and the gene reference database, no external datasets required.
  • simple_conga_pipeline — end-to-end CoNGA run on a single 10x human PBMC dataset.
  • fancy_conga_pipeline_with_batches_and_gammadelta_tcrs — multi-sample batch integration across 22 samples, covering both TCRαβ and TCRγδ lineages.

Note: the colab_conga_pipeline.ipynb notebook isn't rendered here since it's meant to be run live on Google Colab.
